Always use `pnpm` for package management in this project, not npm or yarn.

**Why:** User preference — pnpm is the chosen package manager.

**How to apply:** Use `pnpm` for all install, add, run, and create commands. Use `pnpm create vite`, `pnpm add`, `pnpm run`, etc.
